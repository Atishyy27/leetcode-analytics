LeetCode Rating Analytics

Version 2. Nothing here leaves your browser.

Where it appears

Rating data

Turning this on asks for permission to reach raw.githubusercontent.com and then fetches the dataset once a week. That tells GitHub your IP address and roughly when you use LeetCode. The snapshot that ships with the extension is usually within a week of upstream, since ratings only change when a contest ends. Revoking the permission at your browser's extensions page stops the request immediately; the permission is checked on every single call, not once at startup.

Cache

Checking…

The cache holds your problem list for 12 hours and the rating table if you enabled refresh. Clearing it forces a fresh read the next time you open a profile.

What this extension can see

It reads leetcode.com pages you open and calls the same GraphQL endpoint the site itself calls, signed in as you, to ask which problems you have solved. It stores the answer on your own machine. It has no server, sends no analytics, and the only outbound request it can ever make to a third party is the GitHub one above, which is off unless you turn it on.
